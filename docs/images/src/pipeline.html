how a turn works

一轮对话里，记忆只做四件事：取候选 · 过闸 · 注入 · 落账

每一步都有数字，每一步都能回查——不靠感觉，靠账。
1
取候选
七层库里按关键词 × 重要度 × 时间打分，星图补上邻域，共现自学习把你自己用过的新词扩进来。
  • 本地检索 2.9ms（1200 条库）
  • 星图邻域：按强度闸取 ≤4 条
  • 共现扩词，词源取你自己的 keywords
2
过闸
四道闸各管一段：够不够格、是不是同一轮的话、离第一名多远、额度还够不够。
  • 字面兜底：只对上单字，整轮不注入
  • 问句降档：真问句走 0.21 的线
  • 陪跑线：不到第一名 ×0.2 的不占名额
3
注入
常驻手册只 1,266 字符；命中条目按你给的额度整句挤压，长句咬断接上，宁可少说一句空话。
  • 每轮总额可调，默认不限
  • 单条上限 + 会话预算双层保险
  • 头行、尾巴按余额自动降档
4
落账
进了哪几条、每条多少字、被挡的为什么被挡——都写进同一份日志，面板照旧念得出。
  • picks= 每条真实写入的字数
  • drops= 五种落选原因 + 分数
  • 面板给能照做的对策
常驻注入 1,266 字符
工具 schema 14,494 B
每轮固定开销 约 2.2K token
单次检索 2.9ms p50
67 支自检 / 4,616 条断言
